# PRX-917 사용 가이드 📻

> 처음 써 보는 사람도, 중학생도 따라 할 수 있게 쉽게 설명한 안내서예요.

---

## 1. PRX-917이 뭐예요?

**인터넷이 없어도 쓸 수 있는 "비밀 무전기" 앱**이에요.

보통 카카오톡 같은 메신저는 내 메시지가 **통신사 기지국 → 인터넷 → 회사 서버**를 거쳐 친구에게 가요.
그래서 산속, 바다, 지하, 재난 상황처럼 **신호가 안 터지는 곳**에서는 쓸 수 없죠.

PRX-917은 다르게 동작해요.

```
보통 메신저:   내 폰 → 기지국 → 인터넷 → 서버 → 인터넷 → 기지국 → 친구 폰
PRX-917:      내 폰 ───────────────(블루투스/와이파이 전파)──────────────→ 친구 폰
```

폰과 폰이 **직접** 전파로 이야기해요. 중간에 아무도 거치지 않아요.

### 무전기랑 뭐가 달라요?

| | 일반 무전기 | PRX-917 |
|---|---|---|
| 인터넷 없이 됨 | ✅ | ✅ |
| 다른 사람이 엿들을 수 있음 | 😱 같은 채널이면 다 들림 | 🔒 **못 들어요** (암호화) |
| 가짜로 끼어들 수 있음 | 😱 가능 | 🛡 **안전번호로 막아요** |
| 주고받는 것 | 목소리 | 문자 메시지 |

## 2. 꼭 알아야 할 단어 5개

어려운 말이 나오면 여기를 다시 보세요.

| 단어 | 쉽게 말하면 |
|---|---|
| **암호화** | 메시지를 **자물쇠 상자**에 넣어 보내는 것. 열쇠를 가진 친구만 열 수 있어요. 중간에 누가 상자를 가로채도 안을 볼 수 없어요. |
| **신원키** | 내 폰만 가진 **도장(인감)** 같은 것. "이 메시지는 진짜 내가 보냈다"는 증거예요. 폰 안 금고에 잠겨 있어요. |
| **채널 (CH)** | 무전기의 **방 번호**. CH 3에 있는 사람은 CH 3에 있는 사람만 찾을 수 있어요. |
| **안전번호** | 두 폰 화면에 뜨는 **숫자 암호**. 두 폰의 숫자가 똑같으면 "중간에 끼어든 사람이 없다"는 뜻이에요. |
| **콜사인** | 무전기에서 쓰는 **내 별명**이에요 (예: `DELTA-6`). |

## 3. 준비물

- ✅ **안드로이드 폰 2대** (같은 앱이 깔린 폰끼리만 이야기할 수 있어요)
- ✅ 폰에 **화면 잠금**(지문, 얼굴, PIN 중 하나)이 설정돼 있어야 해요
- ✅ **블루투스**와 **와이파이**를 켜 두세요 (와이파이에 *연결*할 필요는 없어요, 켜기만 하면 돼요)
- ✅ 두 폰이 **가까이** 있어야 해요 (같은 방 ~ 수십 미터 정도)

> ⚠️ **지금은 안드로이드 ↔ 아이폰끼리는 대화할 수 없어요.** 안드로이드는 안드로이드끼리, 아이폰은 아이폰끼리만 돼요. (나중에 고칠 예정이에요)

### 앱 설치하기 (안드로이드)

아직 플레이스토어에 올라가 있지 않아서, 파일(APK)로 직접 설치해요.

1. 어른이나 개발자에게 `app-debug.apk` 파일을 받아요.
2. 폰에서 파일을 눌러 열어요.
3. "출처를 알 수 없는 앱 설치" 경고가 뜨면 **설정 → 이 출처 허용**을 켜요.
4. **설치**를 눌러요.

> 🧑‍🏫 모르는 사람이 보내 준 APK 파일은 절대 설치하지 마세요. 믿을 수 있는 사람에게 받은 파일만 설치해요.

### 처음 실행할 때 나오는 권한 요청

앱이 "근처 기기", "위치" 권한을 물어보면 **허용**을 눌러요.
주변에 있는 폰을 찾으려면 꼭 필요해요. (앱은 내 위치를 어디에도 보내지 않아요.)

## 4. 따라 해 보기: 친구와 첫 대화 🚀

친구와 함께 **두 폰에서 똑같이** 따라 하세요.

### ① 잠금 풀기 🔓

앱을 켜면 잠금 화면이 나와요.

- **"생체인증 또는 기기 PIN으로 잠금 해제"** 버튼을 눌러요. (안드로이드 10 이하 폰은 **"지문/얼굴로 잠금 해제"**라고 나와요)
- 지문이나 얼굴을 대거나, 폰 PIN을 입력해요.

> 💡 왜 잠가 둘까요? 폰을 잃어버려도 다른 사람이 내 이름(신원키)으로 메시지를 보내지 못하게 하려고요.

### ② 채널 고르기 📡

CH 1부터 CH 8까지 버튼이 보여요.

- 친구와 **같은 번호**를 눌러요. (예: 둘 다 **CH 3**)
- 번호가 다르면 서로를 못 찾아요!

### ③ 친구 찾기 🔍

"교신 가능한 국 수신 중…"이라는 글자가 나오고, 잠시 뒤 주변 폰이 목록에 나타나요.

- 목록에 나온 이름을 눌러 연결해요.
- 10초 넘게 안 나오면: 두 폰이 같은 채널인지, 블루투스·와이파이가 켜져 있는지 확인해요.

### ④ 안전번호 확인하기 🛡 (가장 중요!)

연결되면 **숫자가 크게** 나와요. 예를 들면 이런 식이에요.

```
12345 67890 13579
```

- 친구와 **서로 폰 화면을 보여 주거나 소리 내어 읽어서** 숫자를 비교해요.
- **완전히 똑같으면** → **"일치 · 확인"**을 눌러요.
- **하나라도 다르면** → **"불일치"**를 누르고 대화하지 마세요! 누군가 중간에 끼어들었을 수 있어요.

> 🤔 **왜 숫자를 맞춰 봐야 해요?**
> 나쁜 사람이 나와 친구 사이에 몰래 끼어서, 나한테는 "친구인 척", 친구한테는 "나인 척" 할 수 있어요.
> 이걸 **중간자 공격**이라고 해요. 그런데 끼어든 사람이 있으면 두 폰의 숫자가 **반드시 달라져요.**
> 그래서 숫자가 같으면 안심해도 돼요.

### ⑤ 대화하기 💬

- 아래 칸에 메시지를 쓰고 **전송**을 눌러요.
- 화면 위에 **"CH 3 · 암호화됨"**처럼 나오면 자물쇠가 잘 걸려 있는 거예요.
- **"링크 끊김 — 상대 신호 소실"**이 빨갛게 뜨면 거리가 멀어졌거나 친구가 앱을 끈 거예요. 가까이 가서 **재연결**을 눌러요.

## 5. 다른 기능

화면 아래 탭바에 **📡 무전 · 🪪 페어링 · ⚙ 설정** 세 버튼이 있어요.

### 🪪 페어링 (QR로 미리 서로 확인하기)

얼굴을 마주 보고 있을 때, QR 코드로 서로의 신원키를 미리 받아 둘 수 있어요.

1. 한 사람이 **페어링** 탭에서 내 QR 코드를 보여 줘요.
2. 다른 사람이 **"상대 QR 스캔"**을 눌러 카메라로 찍어요.
3. 초록색으로 상대 정보와 안전번호가 나오면 성공!

### ⚙ 설정

| 항목 | 설명 |
|---|---|
| 내 콜사인 | 내 별명. **지금은 모든 폰이 `DELTA-6`으로 같게 나와요** (바꾸는 기능은 준비 중) |
| 기본 채널 | 지금 고른 채널 |
| 생체인증 잠금 | 항상 켜져 있어요. 끌 수 없어요 (안전을 위해) |
| 메시지 자동 삭제 · 수신 알림음 | 스위치는 있지만 **아직 실제로 동작하지 않아요** (준비 중) |
| 신원키 재생성 | 내 "도장"을 새로 만들어요. ⚠️ 그동안 확인했던 친구들과 **안전번호를 다시 확인**해야 해요 |

## 6. 이럴 땐 이렇게 (자주 묻는 질문) ❓

**Q. 잠깐 다른 앱 갔다 왔는데 다시 잠겼어요. 대화도 사라졌어요!**
A. 정상이에요. 앱을 **30초 넘게** 벗어나면 안전을 위해 자동으로 잠기고, 대화 내용과 연결을 **모두 지워요.**
다시 잠금을 풀고, 채널 → 연결 → 안전번호 확인을 하면 돼요. 30초 안에 돌아오면 그대로 이어져요.

**Q. 앱 안에서 스크린샷이 안 찍혀요.**
A. 일부러 막아 둔 거예요. 비밀 대화가 사진으로 남거나, "최근 앱" 화면에 보이지 않게 하려고요.

**Q. "기기에 지문/얼굴 또는 화면 잠금(PIN·패턴)을 먼저 설정하세요"라고 나와요.**
A. 폰 **설정 → 보안**에서 화면 잠금(PIN, 지문 등)을 먼저 만들어 주세요. 잠금이 없는 폰에서는 신원키를 안전하게 지킬 수 없어서 앱이 열리지 않아요.
(안드로이드 10 이하 폰은 PIN만으로는 안 되고 **지문을 꼭 등록**해야 해요.)

**Q. "생체 등록이 바뀌어 신원키가 무효화됐습니다"라고 나와요.**
A. 폰에 지문이나 얼굴을 새로 등록하면, 안전을 위해 예전 신원키 금고가 잠겨 버려요.
**"신원 재생성"**을 누르고 다시 잠금을 풀면 새 신원키가 만들어져요. 친구들과 안전번호를 다시 확인하세요.

**Q. 친구가 목록에 안 나와요.**
A. 이 순서로 확인해 보세요.
1. 둘 다 **같은 채널**인가요?
2. 둘 다 **블루투스·와이파이**가 켜져 있나요?
3. 권한(근처 기기, 위치)을 **허용**했나요?
4. 너무 멀거나 벽이 두껍지 않나요? 가까이 가 보세요.
5. 한쪽이 아이폰이면 아직 연결이 안 돼요.

**Q. 인터넷 데이터가 나가나요?**
A. 아니요. 인터넷을 전혀 쓰지 않아요. 비행기 모드에서도 블루투스·와이파이만 다시 켜면 동작해요.

**Q. 정말 아무도 못 엿들어요?**
A. 메시지 **내용**은 못 봐요. 하지만 이건 알아 두세요.
- 근처에서 "두 폰이 뭔가 주고받고 있다"는 **사실**은 알 수 있어요. (내용은 몰라요)
- 내 폰 자체가 해킹당했거나, 누가 내 어깨 너머로 화면을 보면 지켜 줄 수 없어요.
- **안전번호 확인을 건너뛰면** 보호가 약해져요. 꼭 확인하세요!

## 7. 안전하게 쓰는 약속 5가지 ✋

1. **안전번호는 꼭 확인해요.** 숫자가 다르면 대화하지 않아요.
2. **폰 화면 잠금을 켜 둬요.** 그래야 신원키가 안전해요.
3. **믿을 수 있는 사람에게 받은 APK만 설치해요.**
4. **나쁜 일에 쓰지 않아요.** 남을 괴롭히거나 속이는 데 쓰면 안 돼요.
5. **위급할 땐 119/112가 먼저예요.** PRX-917은 친구끼리 연락하는 도구이고, 긴급 신고 기능은 없어요.
